Esse é um projeto introdutório na linguagem Java.

É a primeira vez que tive contato com essa linguagem, que é o nêmesis de muita gente.
Esse contato foi proporcionado pela Alura, em parceria com o Geração Caldeira 2026, como parte da trilha de Programação Java.

A ideia geral do projeto fiz acompanhando os cursos, mas o restante fiz sozinho, justamente pra aprender na prática.

O projeto faz o seguinte: usando a API do Omdb, conseguimos consultar de forma bem simples por títulos, como filmes e séries. Com esse projeto, presenciei na prática como usar conceitos como herança, encapsulamento, abstração e exceções, sendo esses conceitos essenciais que se extendem por diversas linguagens de programação.
